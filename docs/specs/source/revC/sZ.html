17.0 GLOSSARY [C: renumbered from 13.0]

AttachmentA point-table entry that lies on another layer's path; one-way.
CatalogThe index of library items, worked out from the folders.
CheckpointA working build the owner evaluates before work continues.
CommandA named change to a document; the only way a document changes.
ConnectorA kernel rule joining path points into stitches.
DiscA numbered point placed on a layer: free, or anchored to a path (an attachment).
DocumentPlain JSON describing a drawing or figure; saved; undoable.
FinderA kernel rule naming points on a path by feature.
GeneratorOne file describing one drawable object or script: meta, settings schema, build or run.
HandleA draggable setting of type point; it names a point in the point table.
KernelThe geometry code: values in, values out, no state, no painting.
MakerA kernel rule producing a path: line, circle, parametric curve and so on.
PanelA side area of the page. Replaces one meaning of V1's "overlay".
PathAn ordered array of points, open or closed.
Point tableThe document's list of numbered points; welds are shared entries.
RendererThe only code that paints: canvas, SVG, PDF, nail list.
SessionView state: selection, mode, zoom. Not saved, not undone.
ShaperA kernel rule turning a path into another path.
WeldTwo handles naming one point (shared), or a handle attached to a path.
