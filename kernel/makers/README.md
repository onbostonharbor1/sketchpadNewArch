# kernel/makers

Makers return a path: line, circle (and ellipse, spaced by angle or by arc length), arc, polygon, star, zigzag,
spiral, parametric (adaptive sampling, DS 4.6), roulette (Spirograph curves), points. One file each, every setting
defaulted, returning `{ value, notes }` (RECONCILIATION.md R-4). The prototype's `line` is in `kernel/kernel.js`
and moves here in Stage 3. Source material: V1's `archive/draw/` and the Ideabook routines
(`archive/gallery/Ideabook/scripts/ideabookRoutines.js`).
